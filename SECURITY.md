# Security Policy

## Supported versions

The latest released version is supported.

Please update to the most recent release before reporting a security issue.

---

## Reporting a vulnerability

If you believe you have found a security vulnerability in **Legrand Energy**, please **do not** open a public GitHub issue.

Instead, report it privately by contacting the maintainer through GitHub or by email if a contact address is available.

Please include:

- a description of the vulnerability;
- affected version(s);
- steps to reproduce;
- potential impact;
- any suggested mitigation.

---

## Sensitive information

Never publish or include the following in bug reports, issues, pull requests, or discussions:

- Netatmo account credentials
- OAuth Client ID and Client Secret
- Access tokens
- Refresh tokens
- Session cookies
- WebTokens
- Home Assistant diagnostics containing authentication data
- Any other private authentication information

Please remove or redact sensitive information before sharing logs.

---

## Scope

This integration communicates with both official and undocumented Netatmo web services.

Security reports related to:

- authentication;
- credential storage;
- OAuth handling;
- private API session management;
- sensitive data exposure;

are especially appreciated.

---

Thank you for helping keep Legrand Energy secure.
