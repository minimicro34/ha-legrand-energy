# Contributing to Legrand Energy

Thank you for your interest in contributing to **Legrand Energy**!

Contributions are welcome, whether they are bug fixes, new features, documentation improvements, or test enhancements.

---

## Development environment

Clone the repository and install the development dependencies:

```bash
git clone https://github.com/minimicro34/ha-legrand-energy.git
cd ha-legrand-energy

python -m pip install --upgrade pip
python -m pip install -r requirements_dev.txt
```

---

## Development workflow

Create a dedicated branch for your changes:

```bash
git switch main
git pull
git switch -c feature/my-change
```

Before committing your changes, format the code:

```bash
make format
```

Run the complete local quality checks:

```bash
make check
```

`make check` runs the same checks as the GitHub CI workflow:

- Python bytecode compilation
- Ruff formatting verification
- Ruff lint
- mypy
- pytest

Individual commands are also available:

```bash
make compile
make format
make format-check
make lint
make typecheck
make test
make clean
```

---

## Tests

Please add or update tests whenever a functional change is introduced.

Run the complete test suite:

```bash
make test
```

---

## Pull requests

Before opening a Pull Request:

- Keep the PR focused on a single logical change.
- Rebase or update your branch from the latest `main`.
- Run `make format`.
- Run `make check`.
- Update `CHANGELOG.md` if the change affects users.
- Update the documentation when appropriate.

Please describe:

- what changed;
- why the change was needed;
- how it was tested;
- any compatibility considerations.

---

## Commit messages

Use short, descriptive commit messages written in the imperative mood.

Examples:

```text
Improve private measurement caching
Refactor private measurement decoder
Add measurement service tests
Update README
```

---

## Reporting issues

When reporting a bug, please include:

- Home Assistant version;
- Integration version;
- Installation method (HACS or manual);
- Relevant logs;
- Diagnostics generated by Home Assistant, when possible;
- Steps to reproduce the issue.

Please remove or anonymize any sensitive information before publishing logs.

---

## Security

**Never publish:**

- Netatmo credentials
- OAuth Client Secret
- Access tokens
- Refresh tokens
- Cookies
- WebTokens
- Session identifiers
- Any other private authentication data

---

## Code style

This project follows the Home Assistant development conventions whenever applicable.

Please refer to:

https://developers.home-assistant.io/

All contributions should:

- pass `make check`;
- include tests when appropriate;
- remain fully typed;
- follow the existing project style.
